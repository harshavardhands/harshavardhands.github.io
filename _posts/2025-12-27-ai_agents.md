# From Basics to Real-World Applications (Backend Perspective)

## 🚀 Introduction

If you’re a backend developer (Java, Spring Boot, Python), you already know how systems work:

Controller → Service → Database / APIs → Response

Everything is predictable. You define:
- what happens  
- in what order  
- for every request  

But modern applications are evolving.

Instead of writing:
“First do A, then B, then C”

We now say:
“Here’s the goal — figure out how to achieve it.”

This shift introduces a powerful concept:

## 🤖 AI Agents

## 🧠 What is an AI Agent?

An AI agent is a backend component that uses an LLM (Large Language Model) to decide what actions to take and which APIs/services to call in order to achieve a goal.

---

## 🔁 Traditional vs Agent Thinking

### Traditional backend
```java
if (userRequest.equals("planTrip")) {
    callFlightService();
    callHotelService();
}
```
### AI agent
User: "Plan a trip under ₹20,000"

Agent:

→ decides steps dynamically  
→ calls APIs  
→ returns result  

---

## 🏗️ Where AI Agent Fits in Architecture

### Before AI
Client → Controller → Service → APIs → Response

### After Adding Agent
Client → Controller → Service → Agent → APIs → Response

👉 You are NOT replacing your backend  
👉 You are adding an intelligent orchestration layer  

---

## 🧩 How an AI Agent Works

1. Think → What should I do?  
2. Act → Call API/tool  
3. Observe → Check result  
4. Repeat until goal is complete  

---

## 💻 Minimal Example (Python)

```python
def run_agent(user_input):
    context = user_input

    for _ in range(3):
        response = llm(context)

        if "ACTION" in response:
            action = response.split(":")[1].strip()

            if action == "get_weather":
                result = get_weather()

            elif action == "book_hotel":
                result = book_hotel()

            context += f"\nTool Result: {result}"

        elif "FINAL" in response:
            return response.replace("FINAL:", "")

    return "Could not complete task"
```

## 🛠️ How to Use AI Agents in Your Project (Beginner Level)
**Step 1**: Add a Chat API

```json
POST /ask
{
  "message": "Plan a trip"
}
```

**Step 2**: Connect to LLM

Use any provider:

OpenAI
Anthropic

**Step 3**: Add One Tool (API)

Example:

get_weather()

**Step 4**: Let Agent Decide
User → Agent → Tool → Response

👉 That’s your first working AI agent.

## ⚠️ When NOT to Use AI Agents

Avoid using agents for:

- CRUD operations
- Fixed workflows
- Payment systems
- Critical deterministic logic
